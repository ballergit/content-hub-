# Content Hub — React/Vite

An original, non-explicit content discovery UI built for learning and customization.

## Run locally
1. Install Node.js.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the local Vite URL.

## Build
`npm run build`

## GitHub
Create a repository and upload the project files. Then connect the repository to Vercel or Netlify for deployment.

## Important
Replace placeholder images/text with content you own or have permission to use. This project does not include copied third-party branding or protected media.
